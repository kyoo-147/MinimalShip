# Agent-facing repository material

This directory contains public maintenance guidance for agents working on the MinimalShip bundle. The repository's local-only working material remains under ignored `docs/`, `analysis/`, and `.local/`.

- [Invocation](invocation.md) explains user-invoked and model-invoked skill metadata.
- [Writing docs](writing-docs.md) explains progressive disclosure and verification.
- [Install block](install-block.md) defines the safe distribution boundary.
- [Release](release.md) records the maintainer sequence before publishing.
