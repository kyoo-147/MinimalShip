# Writing public agent documents

Use progressive disclosure:

1. Metadata says when the skill is relevant and whether it is explicit.
2. `SKILL.md` contains the smallest useful workflow and output contract.
3. Supporting files contain checklists, templates, examples, and edge cases.
4. Handbook pages explain the skill to a human maintainer.

Write original English. Prefer concrete inputs, actions, outputs, and verification. Explain why a high-cost rule exists. Avoid copied source text, hidden side effects, generic preambles, and cross-skill dependencies that require a file to be loaded first.
