# MinimalShip scope

MinimalShip is a curated set of product-development skills for AI coding agents and small engineering teams.

## In scope

- user and problem framing
- product discovery and acceptance contracts
- prototypes and vertical slices
- implementation, debugging, testing, and code review
- domain language and module design
- bounded worker orchestration with Pi and optional Herdr
- release preparation, pull requests, cloud or deployment handoffs that require explicit human authority
- skill authoring, installation, metadata, and structural validation

## Out of scope

- startup fundraising, investment advice, founder identity, age, family, or employment decisions
- a hosted cloud platform or autonomous deployment service
- a general-purpose issue tracker, CRM, or backlog product
- copied third-party essays, translations, scraped source archives, or vendor-specific proprietary process text
- framework rewrites, speculative architecture, and agent count as a success metric
- unrelated writing experiments or course-specific utilities

## Acceptance bar for new skills

A proposed skill belongs only when it addresses an observed product-development failure, has a distinct boundary from existing skills, produces a checkable artifact or behavior, and can state how it composes with the current map. Local configuration belongs in the consuming repository, not in the bundle by default.
