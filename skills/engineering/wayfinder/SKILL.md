# Wayfinder

1. State the destination and the user outcome it serves.
2. List the decisions that could change the destination, interfaces, or safety.
3. Draw dependency edges and mark the current frontier.
4. Resolve one decision with research, a prototype, or a grill.
5. Record the decision and remove the node from the open frontier.
6. Convert stable paths into small tickets and stop maintaining the map when it no longer pays for itself.

A wayfinder is successful when it becomes unnecessary, not when it grows into a permanent planning system.
