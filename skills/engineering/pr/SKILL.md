# Pull Request

Use this shape:

- **Summary:** the user problem and the smallest visible change.
- **Behavior:** before and after, with screenshots or examples where useful.
- **Verification:** exact commands and results, including blocked checks.
- **Risk:** blast radius, migration or rollback concern, and security notes.
- **Follow-up:** only work intentionally left outside this change.

Use a Conventional Commit subject. Never claim a CI, review, deployment, or user observation that did not happen.
