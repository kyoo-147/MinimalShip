# Grill Me

Run a decision-first interview for a product or design request.

- Map outcome -> user journey -> constraints -> acceptance -> execution policy -> risk.
- Ask only questions whose prerequisites are settled.
- Put facts discovered from the repository or tools on the agent side.
- Put product choices, trade-offs, permissions, and priorities on the user side.
- Number questions, recommend a default, and let the user accept or change it.
- End with a short contract and one confirmation.

Use the Quick path for ordinary work. Use the Deep path only when unresolved branches could change the product or safety boundary.
