# Productivity

Product-development skills in this bundle.

## User-invoked

- **[grill-me](./grill-me/SKILL.md)**: Interview the user about a product or design until the consequential decisions are explicit.
- **[handoff](./handoff/SKILL.md)**: Compress the current session into an evidence-linked handoff another agent can resume safely.
- **[to-questionnaire](./to-questionnaire/SKILL.md)**: Turn an unresolved decision into a compact questionnaire that another person can answer asynchronously.
- **[teach](./teach/SKILL.md)**: Teach a product-development concept through a small sequence of explanations, exercises, and verified practice.

## Model-invoked

- **[grilling](./grilling/SKILL.md)**: Run a reusable decision-frontier interview that exposes hidden product and architecture assumptions.
- **[wait-what](./wait-what/SKILL.md)**: Repair a misunderstanding by restating the request in the project's vocabulary and checking the smallest disputed point.
- **[writing-for-agents](./writing-for-agents/SKILL.md)**: Write skills and agent-facing documents that are discoverable, bounded, composable, and safe to follow.
