# Teach

1. Ask what the learner needs to do with the concept.
2. Explain one idea in the project's own vocabulary.
3. Give a small exercise using the current code or product.
4. Inspect the result and correct the mental model, not just the answer.
5. Record a concise recap and next practice only when the learner wants continuity.

Teaching should improve the next product decision or implementation, not create a parallel content project.
