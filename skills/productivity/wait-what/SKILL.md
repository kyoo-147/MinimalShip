# Wait, What?

When a message does not land:

1. Stop building on the disputed interpretation.
2. Restate the request in plain language and current domain terms.
3. Name the exact consequence of each interpretation.
4. Ask one small confirmation question.
5. Update the work record and continue only after the meaning is stable.

Do not hide a semantic mismatch behind a large implementation.
