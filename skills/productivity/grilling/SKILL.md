# Grilling

Use this discipline when the product or design tree matters more than speed of the first edit.

- Build outcome -> journey -> constraints -> acceptance -> execution -> risk.
- Keep questions whose prerequisites are open out of the current round.
- Ask in compact numbered groups and propose a sensible default.
- Record answers once and reuse them.
- Finish when no consequential decision remains open.

A grill is not a license for endless questioning. Reversible details belong in implementation.
